Translator

网页转中文 Markdown

直接输入单个 URL，或者上传一个每行一个地址的 url.txt。后端会调用当前 translator 管线， 输出适合继续阅读、预览和归档的 Markdown 文件。

单 URL 一条链接直接生成一个 Markdown 下载文件。
批量 按行读取、忽略空行与注释，完成后统一打包为 ZIP。
纯 Python 不依赖 Node 构建，Windows 与 WSL 共用同一套后端能力。
